1. Що таке структурне програмування?
Структурне програмування — це методологічний підхід до написання програмного коду, який представляє програму у вигляді структури з набору блоків, розташованих в ієрархічній послідовності.
2. Назвіть основні конструкції структурного програмування.
Структурна програма використовує тільки три конструкції:
послідовне виконання — «виконати дію 1, виконати дію 2»;
розгалуження — «якщо умова дотримана, виконати дію 1, інакше дію 2»;
цикл — «поки умова дотримується, виконувати дію 1».
3. Назвіть основні принципи структурного програмування.
Ключові правила та принципиТеорема Бема-Бопліні: будь-яку складну програму можна представити через комбінацію трьох базових конструкцій: послідовності, розгалуження та циклу.Відмова від goto: заборона використання неконтрольованих переходів, що робить код зрозумілішим і позбавляє його "спагеті-структури".Земне проектування (згори вниз): поділ великої задачі на менші, незалежні підзадачі (процедури або функції), які вирішуються окремо.Модульність: код розбивається на логічні блоки з єдиним входом та єдиним виходом.
4. Поясніть, чому в деяких мовах програмування не радять використовувати оператор GOTO, а в мові Java його взагалі немає?
Оператор goto вважається шкідливим у сучасному програмуванні через те, що він сильно ускладнює читання, розуміння та підтримку коду.
А в java його немає тому що практично будь-яку задачу, яку раніше вирішували за допомогою goto, в Java можна елегантно зробити іншими інструментами.
5. Що таке "спагеті-код"?
spaghetti code - це коли ваші системи мають стільки залежностей від зовнішніх посилань, що видалення однієї залежності зламає багато речей.
6. Що таке проєктування згори-вниз?
Проєктування згори-вниз (top-down design) — це підхід до розробки систем, коли спочатку створюють загальну концепцію чи головний каркас, а потім поступово деталізують і розбивають його на менші складові частини
7. Що таке область видимості ідентифікатора?
Область видимості ідентифікатора (Scope) — це частина вихідного тексту програми, в якій цей ідентифікатор (назва змінної, функції, константи чи типу) є доступним для використання
Їх види це Local Scope та Global Scope, перший це ідентифікатор оголошується всередині певного блоку коду, функції чи фігурних дужок. Він доступний лише всередині цього блоку
а другий ідентифікатор оголошується поза всіма функціями чи блоками. Він доступний у будь-якій частині програми після його оголошення
8. Що таке блок? Як блоки впливають на область видимості?
Блок у програмуванні — це група інструкцій, об’єднана всередині фігурних скобок { ... }. Блоки використовуються для логічної групування коду у функціях, циклах (for, while) та умовних операторах (if/else). Блоки безпосередньо керують областю видимості (scope) — зонного коду, в якому змінні доступні для використання.

13. До якого результату призведе виконання наступного фрагменту коду? Перевірте. Поясніть.
        boolean a = false;
        boolean b = false;
        if (a = false) {
            System.out.println("a is false");
        }
        if (b = true) {
            System.out.println("b is true");
        }
        if (a = b) {
            System.out.println("a = b");
        }
оператор = у Java використовується для присвоєння, а не для порівняння.
буде b is true
a = b але ми просто присвоюємо значення і не прерівнюєм його тому коли компілятор натикаєть на умову b = true він його присвоює а = b
14. До якого результату призведе виконання наступного фрагменту коду? Перевірте. Поясніть.
        int a = 1;
        a++;
        ++a;
        switch(a) {
            case 1: System.out.println("1");
            case 2: System.out.println("2");
            case 3: System.out.println("3");
            case 4: System.out.println("4");
        }
У результаті виконання програми отримуємо 3 4. Спочатку змінна a має значення 1, оператор a++ збільшує її до 2, а ++a — до 3. Після цього switch знаходить case 3 і виводить число 3. Оскільки після case 3 немає оператора break, виконання продовжується і для case 4, тому також виводиться 4.
15. До якого результату призведе виконання наступного фрагменту коду (true/false)? Перевірте. Поясніть.
        double sum = 0;
        // Let's find: 1 + 1/2 + 1/3 + 1/4 + 1/5 + ...
        for(int i=1; i < 10; i++) {
            sum = sum + 1/i;
        }
        System.out.println(sum > 1);
Програма виведе false. Хоча змінна sum має тип double, вираз 1/i виконується як цілочисельне ділення, оскільки 1 та i мають тип int. Тому при i від 2 до 9 результат 1/i дорівнює 0. У результаті sum залишається рівною 1.0. Перевірка sum > 1 дає false.
